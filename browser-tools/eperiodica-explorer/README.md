# eperiodica-explorer: API tool for e-periodica

Download metadata, full texts and images of Swiss journals from [e-periodica](https://www.e-periodica.ch/), directly in the browser, without programming and without installation.

**▶ Open the tool:** [English](https://k-woitas.github.io/eperiodica-explorer/) · [Deutsch](https://k-woitas.github.io/eperiodica-explorer/de/)

## Instructions for use

The [README of the source repository](https://github.com/k-woitas/eperiodica-explorer#readme) lists all downloadable formats and the terms of use of e-periodica. [PROXY.md](https://github.com/k-woitas/eperiodica-explorer/blob/main/PROXY.md) explains how to unlock all functions with your own CORS proxy.

Alternatively, download [`index.html`](index.html) (English) or [`de/index.html`](de/index.html) (German) and open the file in your browser.

> **This folder is a mirror.** The leading repository is **[k-woitas/eperiodica-explorer](https://github.com/k-woitas/eperiodica-explorer)**. The files here are updated automatically from there; please report issues and suggestions in the source repository.
