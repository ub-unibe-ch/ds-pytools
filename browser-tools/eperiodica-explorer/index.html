Download an article

One input for all downloads of an article: PID (), DOI () or an e-periodica link. One selection gives a single file, several give a ZIP. Content marked Proxy is blocked by e-periodica for browser scripts; without a proxy it appears as a direct link.

Options

e-periodica offers metadata as Dublin Core (oai_dc) only. JSON and CSV split the journal details (journal, ZDB ID, ISSN, volume, year, issue, start page) into separate columns. If the OAI interface cannot be reached, JSON, CSV, RIS and BibTeX are taken from DataCite (for a DOI) or, simplified, from the IIIF manifest. The full text is produced in your browser by text recognition (OCR) from the page images – automatically and not free of errors, especially with Fraktur, tables and poor scans. Columns are read one after the other, illustrations are left out; it takes a few seconds per page. The PDF is only offered as a link, as e-periodica requires a verification in the browser before delivering it.

Pages

The article as PID, DOI or link, plus image numbers such as 2, 1-3 or all. The image number counts the digitised pages of the article from 1; the printed page number is shown in the preview. Text is obtained by text recognition (OCR) from the page images.

Several pages: text as one file with separator lines, images as a ZIP. Publishing images in print, online or on social media requires the prior consent of the rights holders (terms of use).

Harvest a collection

Metadata of a set via OAI-PMH, optionally limited to a time period. e-periodica offers its articles in sets: individual journals and subject groups according to the Dewey Decimal Classification (DDC). Large sets contain many thousands of articles, so limit the number of records. Additional content per article increases the run time considerably.

Please note the terms of use of e-periodica: use is permitted for private, non-commercial and educational purposes; systematically storing larger parts of the offering on other servers requires the written consent of the rights holders and ETH Library. Harvest only what your project needs.

Additionally per article (optional)

Text recognition takes a few seconds per page – for many articles, plan for a long run time.

Check access

Tests which interfaces your browser may read directly and which ones only work via the proxy. The result is used automatically: blocked content is offered as a direct link or loaded via the proxy.

CORS-Proxy (optional)

A CORS proxy forwards requests that e-periodica blocks for browser scripts and thereby unlocks all functions of this page, e.g. harvesting and current platform details.

{url} is replaced by the (encoded) target address; without {url} the address is appended. The proxy must allow www.e-periodica.ch and the image server iiif.library.ethz.ch. Public proxies see all requests and are often throttled – for regular use, run your own proxy (instructions).
