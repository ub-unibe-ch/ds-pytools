# Browser tools

Tools that run directly in the web browser: no programming, no installation, no account. Each tool is a single HTML page that can be used online or downloaded and opened locally.

| Tool | What it does | Use online |
|---|---|---|
| [erara-explorer](erara-explorer/) | Download metadata, full texts, entities and images from [e-rara](https://www.e-rara.ch/) and [e-manuscripta](https://www.e-manuscripta.ch/) | [English](https://k-woitas.github.io/erara-explorer/) · [Deutsch](https://k-woitas.github.io/erara-explorer/de/) |
| [eperiodica-explorer](eperiodica-explorer/) | Download metadata, full texts (OCR) and images of Swiss journals from [e-periodica](https://www.e-periodica.ch/) | [English](https://k-woitas.github.io/eperiodica-explorer/) · [Deutsch](https://k-woitas.github.io/eperiodica-explorer/de/) |

The tools in this folder are mirrors. They are developed in their own repositories and copied here automatically; please report issues and suggestions in the respective source repository.
