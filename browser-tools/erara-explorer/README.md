# erara-explorer: Data tool for e-rara and e-manuscripta

## Contents

- [Files](#files)
- [More information](#more-information)

> [!NOTE]
> **This folder is a mirror.** The leading repository is **[k-woitas/erara-explorer](https://github.com/k-woitas/erara-explorer)**. The files here are updated automatically from there; please report issues and suggestions in the source repository.

Download metadata, full texts, entities and images from [e-rara](https://www.e-rara.ch/) (printed works) and [e-manuscripta](https://www.e-manuscripta.ch/) (manuscripts), directly in the browser, without programming and without installation.

**▶ Open the tool:** [English](https://k-woitas.github.io/erara-explorer/) · [Deutsch](https://k-woitas.github.io/erara-explorer/de/)

Alternatively, download [`index.html`](index.html) (English) or [`de/index.html`](de/index.html) (German) and open the file in your browser.
