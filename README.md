# Digital Scholarship Toolbox

## Contents

- [Tools](#tools)

Simple tools for data handling and analysis in research: Python notebooks and no-code browser tools.

This repository contains examples of how to solve various data analysis problems in research. Most examples are presented as [Jupyter notebooks](http://jupyter.org); installation instructions for the Python libraries required by the different tools can be found in the corresponding notebooks.

Kindly brought to you by [Digital Scholarship Services](https://www.ub.unibe.ch/services/digital_scholarship/index_eng.html) of the University Library Bern, who are also happy to help with hints and questions.

## Tools

| Folder | What it covers | Format |
|---|---|---|
| **Get data** | | |
| [Literature_handling](Literature_handling/) | Scholarly publication data via the Crossref and OpenAlex APIs | Python notebooks |
| [SRU](SRU/) | Library catalogue queries via SRU (in German) | Python notebooks |
| [Swissdox@LiRI](Swissdox@LiRI/) | Swiss news articles via the Swissdox@LiRI API | Python notebooks |

| **Process data** | | |

| [NLP](NLP/) | Basic natural language processing with NLTK | Python notebooks and scripts |
| **No-code browser tools** | | |
| [browser-tools](browser-tools/) | [erara-explorer](browser-tools/erara-explorer/): download metadata, full texts, entities and images from e-rara and e-manuscripta | HTML, runs in the browser |
