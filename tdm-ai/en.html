  • Works: metadata, queries, filters, facets, cursors, citation formats, retractions, relations
  • Funders, members, journals, prefixes, types and licences
  • Habanero Python client library

Key links

  • REST API
  • Crossref Text and Data Mining
  • Public data files (dumps)

API key

  • not required; higher limits with the mailto parameter (“polite pool”)

Content, formats and quotas

  • REST API: metadata on works, journals, members, funders etc.; JSON
  • Per work, full-text links (field link, e.g. for text mining) and licence URLs (field license); filter full-text.application

Terms of use

  • No contract; metadata “free to use”, some abstracts may be protected; funder data CC0
  • Access to the full text behind a Crossref link remains controlled by the publisher

ScopusTDM not specifiedAI permitted

Key links

  • Scopus APIs · API Specification
  • Swagger portal Interactive Scopus APIs
  • Getting Started Guide

API key

  • Account on the Developer Portal and API key

Content, formats and quotas

  • Scopus Search API: metadata; JSON, Atom, XML; 20,000 requests/week, 9 per second
  • Abstract Retrieval API: abstracts linked to author and affiliation profiles; 10,000/week
  • Author Retrieval API: author profiles; 5000/week
  • Affiliation Retrieval API: institution profiles; JSON, XML; 5000/week
  • Serial Title API: journal data by ISSN with metrics (CiteScore, SJR, SNIP); JSON, XML; 20,000/week

Contract terms (excerpt)

  • TDM is neither permitted nor prohibited, i.e. not covered; analysing and processing only permitted with a closed AI tool
  • Access routes: robots, crawlers, automated downloads and systematic storage are prohibited; the contract does not cover the Scopus APIs
  • Uses not covered, such as TDM, can be notified to Elsevier; if there is no objection within 30 days, they are deemed permitted
  • AI use in a closed AI tool permitted, including training; open AI tools prohibited
  • Metadata on the university's own output may go into the repository
  • Per website, non-commercial use only
